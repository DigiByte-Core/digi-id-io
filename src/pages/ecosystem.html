What we need

  • Name, category (wallet, library, plugin or app) and a description up to 160 characters
  • An HTTPS project URL
  • An SVG or PNG logo, max 50 KB
  • A proof link showing Digi-ID support today: docs, source or a page where sign-in can be tried

Pull requests are checked automatically against the ecosystem schema.
