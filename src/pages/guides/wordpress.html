Add Digi-ID to WordPress

The Digi-ID Authentication plugin extends the standard WordPress login with Digi-ID. Here's how to install it and try it safely.

Heads-up: this plugin is unmaintained.

It was last tested with WordPress 4.1. Try it on a staging copy of your site first, and consider contributing fixes upstream. For production sites on current WordPress, a small custom plugin built on digiid-php (see below) may be the safer path.

1. Check requirements

  • HTTPS on your site — wallets post the signature to your server.
  • The PHP GMP extension, used for the signature maths.
php -m | grep -i gmp    # prints "gmp" when the extension is installed

If it's missing, ask your host to enable it (on Debian/Ubuntu: sudo apt install php-gmp and restart PHP).

2. Install and activate


      
Or download the repository as a ZIP, upload it under Plugins → Add New → Upload Plugin, and activate Digi-ID Authentication.


      
3. Try it

      
    
        
  1. Open /wp-login.php on your staging site; the plugin adds a Digi-ID QR code to the login form.
    2. 
        
  2. Scan it with a Digi-ID-capable DigiByte wallet and approve.
    3. 
        
  3. Follow the plugin's prompts to associate the wallet with your WordPress user.
    4. 
      


      
Building your own WordPress integration

      
If the plugin doesn't fit your WordPress version, the moving parts are small:

      
    
        
  • Two REST routes (register_rest_route): one issues a challenge, one receives the wallet callback. Port the logic from the PHP quickstart, which uses DigiID.php from digiid-php.
    • 
        
  • Store nonces in a custom table or transients with a 90-second expiry (see Nonces & replay protection).
    • 
        
  • Store linked addresses in user meta and sign the user in with wp_set_auth_cookie() once the browser's poll sees a verified challenge.
    • 
        
  • Follow the account linking guide so existing users can add Digi-ID to their accounts.
