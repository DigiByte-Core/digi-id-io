Terms of Use & Privacy

digi-id.io is an open-source, volunteer-run website about the Digi-ID protocol. It has no accounts, sells nothing and does not track you. The short version: use it freely, at your own risk, and nothing you do here is collected by us.

Privacy policy

What we collect

Nothing. The site has no sign-up, no forms that send data to us, no analytics and no advertising or tracking cookies.

What stays in your browser

  • Theme choice: if you switch between light and dark mode, the choice is saved in your browser's local storage so it persists. It never leaves your device.
  • Preferred code language: the language tab you pick in code samples is remembered the same way.
  • Demo keys: held in memory only and discarded when you leave or refresh the page.

You can clear these at any time by clearing this site's data in your browser settings.

Hosting

The site is served as static files by GitHub Pages. Like any web host, GitHub may process technical data such as your IP address to deliver pages and protect its service; see the GitHub Privacy Statement. Fonts, icons and scripts are served from this site, not from third-party CDNs.

Embedded video

The explainer video is not loaded until you press play. When you do, it is embedded from YouTube's privacy-enhanced domain (youtube-nocookie.com), and YouTube's privacy policy applies to that playback.

GitHub interactions

If you open an issue, discussion or pull request, that happens on GitHub under your GitHub account and is public.

Children

The site is not directed at children and collects no personal information from anyone.

Questions

Questions about these terms or this policy can be raised in GitHub Discussions or as an issue. See also the disclaimer.
