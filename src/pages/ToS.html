Terms of Use & Privacy

digi-id.io is an open-source, volunteer-run website about the Digi-ID protocol. It has no accounts, sells nothing and does not track you. The short version: use it freely, at your own risk. The only personal data that leaves your browser is what you choose to send through the optional contact form.

Privacy policy

What we collect

The site has no sign-up, no analytics and no advertising or tracking cookies. The only feature that accepts personal information is the optional contact form.

Contact form

If you submit the contact form, the name, email, organization, interest and message you enter are sent from your browser to Web3Forms, a form processor that forwards them by email to a volunteer DigiByte community member. They are used only to reply to you and are not published, sold or added to mailing lists. Nothing is sent unless you press “Send message”. See the Web3Forms privacy policy. To ask for a message to be deleted, contact us via GitHub Discussions without posting personal details.

What stays in your browser

  • Theme choice: if you switch between light and dark mode, the choice is saved in your browser's local storage so it persists. It never leaves your device.
  • Preferred code language: the language tab you pick in code samples is remembered the same way.
  • Demo keys: held in memory only and discarded when you leave or refresh the page.

You can clear these at any time by clearing this site's data in your browser settings.

Hosting

The site is served as static files by GitHub Pages. Like any web host, GitHub may process technical data such as your IP address to deliver pages and protect its service; see the GitHub Privacy Statement. Fonts, icons, scripts and the explainer video are served from this site, not from third-party CDNs.

GitHub interactions

If you open an issue, discussion or pull request, that happens on GitHub under your GitHub account and is public.

Children

The site is not directed at children and does not knowingly collect personal information from children.

Questions

Questions about these terms or this policy can be raised in GitHub Discussions or as an issue. See also the disclaimer.
